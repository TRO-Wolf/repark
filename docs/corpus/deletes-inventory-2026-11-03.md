| Axis | Values | Failure states each value needs |
|---|---|---|
| format | Parquet, Avro, ORC delete files over Parquet, Avro, ORC data | Avro and ORC delete files are EXCLUDED from the v2 label this round by owner ruling; their rows are follow-ups |
| delete kind | position, equality, deletion vector (v3), mixed | a delete that does not apply (a deleted row returned) is S2; a delete that applies to the wrong rows is S1 |
| evolution step | key column dropped, renamed, re-added, type promoted; identifier field removed | the read refuses, or returns rows the delete removed |
