## Interaction axes and failure states

| Axis | Values | Failure states each value needs |
|---|---|---|
| hint state | current, one behind, first version, past the newest, missing, empty, non-numeric, leading space, trailing newline, CRLF, negative, zero, beyond Java `int`, unreadable (mode 000), a directory | each parse failure falls to the listing; a parsed number that names no file refuses; zero means no table |
| metadata-file name form | `v<N>.metadata.json`, `v<N>.gz.metadata.json`, `v<N>.metadata.json.gz`, a catalog-style `NNNNN-<uuid>.metadata.json` beside them, a gzip name over plain bytes, a plain name over gzip bytes | Java probes the three `v<N>` names in codec order and ignores the catalog-style name; the codec comes from the name |
| cleanup state | none, a gap one version below the newest, versions older than the last two removed, the writer's own `delete-after-commit` cleanup | the hint walk stops at the first missing version; the listing takes the highest existing one |
| read door | path read (`load(<location>)`), catalog read (`SELECT` through a `type=hadoop` catalog), `SHOW TABLES`, the native door | RePark's `type=hadoop` catalog does not read tables already on disk, so only the path read discovers |
| writer | Spark plain, Spark gzip, Spark mixed codec, Spark with cleanup, RePark plain, RePark under the gzip property, RePark with cleanup | a RePark writer under the gzip property writes plain names |

The pilot measured every combination of the first three axes over the seven writers on the path read and the path write (1890 fixtures, plus 20 checksum-sidecar controls), and the catalog doors on control fixtures: [hadoop-discovery-cells-2026-11-03.jsonl](hadoop-discovery-cells-2026-11-03.jsonl).
