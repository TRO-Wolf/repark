RePark · Iceberg closeout · adopted 2026-10-20

Zone Seam Plan

The owner asked what pathway puts RePark on a stable, reliable path on par with Spark. The answer: stop gating symptoms at the write doors, fix the one zone conversion underneath them, and prove parity where Spark can be measured cheaply. Adopted the same evening ("Do it, proceed with recommendations and implementation").

1. What the evidence says

Every timestamp unit since v1.5.3 has been the same defect seen from a different door: R-007 (the MERGE wall), R-015 and R-011 (nested leaves), ENC-1, and now the container cast. RePark converts a zoned timestamp on two paths.

matches Spark the leaf cast

CAST(x AS TIMESTAMP_NTZ) is lowered at the SQL AST to the UDF __repark_cast_timestamp_ntz__, which reads spark.sql.session.timeZone. Every leaf spelling the U-8 verifier tried stores the session wall.

renders in UTC everything else

A CAST/TRY_CAST of a struct, array or map holding a zoned leaf, and to_json, go through DataFusion's native cast. Measured wrong in a plain SELECT, in every write, and in the six table-creating writers (CTAS, CREATE OR REPLACE … AS SELECT, REPLACE TABLE … AS SELECT, saveAsTable, writeTo().create()/.replace()/.createOrReplace()).

U-8's gate sits downstream of that split. Each verifier round found a new shape that slipped past it, and each patch over-refused a correct cell somewhere else. Two rounds in: 360 refusals, four cells of over-refusal, and still a silent wrong wall through STRING, DATE, BIGINT and JSON routes. That loop does not converge.

2. The pathway, in order

1. One zone seam. A single Rust conversion point that every zoned-to-naive, zoned-to-string and zoned-to-date operation passes through, container casts and to_json included, reusing the leaf UDFs that already exist. Once the cast is right a plain SELECT is right, and every door inherits it because a write stores what SELECT yields. Unit ZONE-SEAM-1.
2. Expression-level oracle, not door matrices. Record Spark 4.1.2 once over a generated corpus of value sources × conversions × containers × target types × zones on plain SELECT (about 1,500 cells) and replay it on RePark, asserting the exact set of cells that differ on main so a fix and a regression both show. A shape EQUAL on SELECT needs no per-door write cell. Unit ZONE-ORACLE-1, the seam's pin and the nightly's guard.
3. Refuse only what Spark refuses. Rulings 136 and 138 (EXPLAIN ANALYZE of DML, PREPARE of a write) are true parity. A refusal that exists because RePark's own cast is wrong is debt with an eviction date. After the seam lands, GATE-RETIRE-1 removes the R-011 and R-015 arms the seam makes unreachable and keeps the ones Spark shares.
4. No panic reaches a user. map('a', <column>) panics inside DataFusion's map constructor through a caught boundary. The panic ban covers RePark's crates, not its dependencies. MAP-COLUMN-PANIC-1 fixes the lowering and adds a boundary pin that a caught panic is a test failure.

4. What it costs and what it buys

  • Dates. The v2 label slips about a week, from 11-05 to 11-10. The alternative, labelling v2 on time with nested timestamps still rated EXPERIMENTAL (the 2026-10-13 re-rating) and the seam as a v3 precondition, stays open to the owner; the plan takes the slip, because a reader that stores a wrong wall through CTAS should not carry a production label.
  • Fewer rounds. One seam unit with one corpus replaces the per-door gate rounds; the U-8 pattern (build, verify, fix, verify, fix) was two Opus days for one door family.
  • A guard that lasts. The corpus is a fixture; the nightly replays it. A future zone regression shows as a cell leaving or joining the difference list, not as a verifier finding weeks later.
