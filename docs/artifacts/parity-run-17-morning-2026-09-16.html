What the night taught

  • Reviewer reasoning is not a measurement, in both directions. The freqItems signed-zero P1 was real but argued from doubleToLongBits; live Spark showed primitive equality, the opposite on both counts. A critic's P1 about mode's tie behaviour was refuted by the same method. A pin already on main asserted hour(lit(time)) returns 12; Spark raises UNSUPPORTED_TIME_TYPE on both doors.
  • A gate that is a subset of CI is a rehearsal. A local gate of three hand-picked parity files let a census pin through to CI; the chain template gets the whole suite.
  • The merge queue is read with a literal head -1. A comment line at the top stalled every merge for thirteen minutes; entries now sort above the notes.
  • Thin clones borrow objects. A clone made with --shared depends on its build clone; delete dependents first, and never a running run's lanes.
  • Measure the blast radius before carding a type change. LOGICAL-WIDTH-1 looked cross-cutting and turned out to be four match arms once the engine's real behaviour was probed.
