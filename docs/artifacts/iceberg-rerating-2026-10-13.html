What keeps v2 from PRODUCTION

Under the PR #1044 definition a capability is assessed on its own and strength in one attribute does not offset weakness in another. Five things hold the v2 label where it is, in cost-of-failure order.

  • Silent wrong values reachable on v2. Struct field pairing (R-016), the write carriers (WRITE-BODY-CARRIERS-1) and the nested NTZ wall split (R-011, parked). A parked row is not a declared refusal; the production-grade page lists silent fallbacks as disqualifying however well the rest is tested.
  • Four unfixed boundary findings. PA-01 credential disclosure in dbt, PA-02 local-file policy bypass through EXPLAIN ANALYZE COPY, PA-03 symlink escape through a missing parent, PA-04 non-ASCII path panic. The code at each cited line is unchanged on today's main. These are small and independently reproducible.
  • Data-integrity evidence is offline only. The ambiguous-commit path has pinned Rust tests and no live drill; there is no process-kill test on an Iceberg write (only the microbatch crash tests); there is no cross-release pin that reads and writes a table the 1.5.1 wheel produced.
  • No cross-reader evidence on AWS. The owner named Spark and Trino as the production readers on 2026-09-14. Spark reads RePark writes equal on local catalogs; on Glue and S3 Tables it has never been run.
  • Resource bound unstated. The scan, the ordered-write sort and the MoR MERGE retain state outside the pool, and memory detection misses nested cgroups (PA-10). Magnitudes are unmeasured; the envelope must state a size until they are.

Why v3 splits in two

The twenty north-star rows are green or dated DECLARED, and the two live v3 legs passed this morning. That core deserves the same label as v2. The nanosecond family is different in kind: Spark 4.1.2 with Iceberg 1.11 refuses to open any table with a timestamp_ns or timestamptz_ns column, so every such table RePark writes has no oracle and no second reader. Three verifier rounds on the coercion fix each found a new set of spellings that drop digits. The owner's 2026-10-13 rulings narrow that fix to store-column feeders, refuse unasked nanosecond columns at the create door, and refuse the nanosecond array at applyInPandas. Until those three land and R-009 floors on every door, the honest label for a nanosecond column is EXPERIMENTAL and the guide's nanosecond section should open with the Spark-unreadability sentence.
