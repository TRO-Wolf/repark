What the night taught

  • One build clone was the bottleneck. Every remaining family needs Rust, and a run could land at most two Rust units a night. Today allows two build clones per run.
  • Thin clones share objects with the build clone. Deleting the build clone first corrupted a lane and produced two false test failures. Dependents go first now, and the rule is in the runbook brief.
  • A green PR waited hours for a hand-agreed merge slot. The runs now order merges through one queue file.
  • The oracle overturned four reviewer claims in run 15c alone. Live PySpark cells before the critic, every time.
  • Devin's free tier rate-limited two rounds and a box-wide network blip at 04:17 cost one Muse round per run. Resume from the session recovered each one.
