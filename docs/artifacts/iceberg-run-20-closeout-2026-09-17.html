What review caught that a gate would not

  • Mixed-case, four P1s. The first design turned identifier normalization off on the Spark door. SELECT * FROM NUMS, mixed-case CTE and window names all answer on main and would have failed; the unit's own pins used lower-case names, so the suite stayed green.
  • NaN pushdown, P1. The pins proved rows, not pushdown: the ledger claimed a plan pin that did not exist.
  • Dynamic overwrite, P1. An in-band /*RSOW*/ marker in statement text decided overwrite semantics, so a user's comment or string literal could change them. Replaced by a typed flag.
  • Sorted insert, two P1s. sort_order_id stamped on bytes that are not sorted, and a MERGE pin that stays green when the stamp is reverted. Held off main for that reason.
  • Write options, two P1s. A spliced OPTIONS(...) clause let user SQL add snapshot properties Spark never accepts, and the hand-written lexer corrupted UTF-8.
  • A reviewer overturned by measurement. On min-file-size-bytes=-1 the live oracle showed Spark rejects the value, the opposite of the reviewer's premise. The fix follows the measurement.
