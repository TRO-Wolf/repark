Iceberg Closeout Plan

The work that moves the two format-version labels from HARDENED-NARROW to PRODUCTION under the per-capability definition in PR #1044, drawn as thirteen units with a lane, a grade and an exit proof each, ordered over four weeks with two Opus 5.5 lanes. Main is be011012; v1.5.5 is on the merge queue behind the quinn-proto lock bump.

1. What each tag has to prove

Production grade is granted per capability and never averaged. A label moves when every row below for that label is green on main with a dated pin, or carries a dated owner carve-out. Silent values disqualify; a refusal with a hint does not.

v2 HARDENED-NARROW → PRODUCTION

  • No silent value from any door. R-016 struct pairing conformed to Spark's rule or struct writes refused with a hint (U-6); the CTAS write body refuses at parse (U-7); the nested microsecond NTZ wall, R-011, refused or fixed (U-8).
  • Boundary and secrecy. PA-01 to PA-04 closed (U-5); ENC-1 residue items 1 to 6 ruled (U-12). ENC-CTAS-REPLACE-1 (an orphan unencrypted file under a keyed table, never served; both doors: Spark SQL ctas.rs::finish_ctas_staged_commit and ANSI create_table.rs::execute_staged_create and publish_staged_with_summary) closed or carved out (owner ruling 98, 2026-10-15; owner ruling 108 names both doors).
  • Integrity under failure. Kill-mid-write pin, the unknown-commit-outcome drill run live on Glue and S3 Tables, a cross-release read pin (U-9).
  • A second engine reads what we write. Spark 4.1.2 reads every table the eleven acceptance legs write (U-10).
  • A stated resource bound. Ordered writes and MoR MERGE measured, the bound written down, exceeded means refused (U-11).
  • Truth-up. Fresh 842-cell count on the release build, registry rows re-dated, STATUS maturity section (U-13).

v3 core HARDENED-NARROW → PRODUCTION

  • Everything on the v2 list, measured on v3 tables too. Every U-5 to U-11 pin runs on both format versions; the matrix cells are per version already.
  • v3 features exercised stay green. Row lineage, deletion vectors, default values, the twenty north-star rows (all ✅ or DECLARED on 10-13).
  • Nanosecond columns leave EXPERIMENTAL. R-017 by the type planner (U-1), R-020 by the dtype floor (U-2), R-009 one floor on every door (U-3), R-012 message class (U-4), then R-010, R-013, R-018(1) and R-001 measured on the planner head.
  • Dated carve-outs the label carries. R-002: no second engine reads a nanosecond column, so nanosecond columns are labelled HARDENED-NARROW on their own row, not PRODUCTION, until one does. Nested nanosecond leaves refused by name (R-015, card ICE-TSNS-NESTED-1). Variant to 1.6. Streaming sink under C-1.

The honest line for v3. The format-version label can reach PRODUCTION for the workloads we exercise. The nanosecond sub-capability cannot, by the definition's own cross-engine attribute, while Spark cannot read the column. The plan therefore ships v3 PRODUCTION with a dated R-002 carve-out row, which the owner signs (decision T-2), rather than waiting on an engine we do not control.
