# map — docs/perf/config-profiles-2026-09-12

## Purpose

Raw sweep CSVs for PROFILES-1 step 2, the evidence for every number in
[../config-profiles-2026-09-12.md](../config-profiles-2026-09-12.md). One CSV per
knob plus `baseline.csv`; row shape `dataset,query,knob,value,repetition,seconds`
(three repetitions per cell, `@default` = the knob unset). The C-008 pin
recomputes every doc table from these files. Generated by
`python/repark-parity/bench/profiles/run_profiles.py` on a release module, quiet
box, full scale.
