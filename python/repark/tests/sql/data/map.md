# map — python/repark/tests/sql/data

## Purpose

Measured cell tables that a facade SQL pin reads as its clause.

## Contents

- [ident_dialect_1_cells.jsonl](ident_dialect_1_cells.jsonl) — the AUD-015 domain table:
  1144 cells (13 heads x 22 target spellings x a temporary view of the target's name or
  none x the memory and hadoop catalogs), each with Spark 4.1.2's answer and state change
  (hadoop catalog) and RePark's at 4fd5c6c1; 28 delta cells (a relation after a comma or
  JOIN in a FROM clause, 14 statements x both catalogs) with RePark's answer at c3c2a76b;
  16 IDENT-DIALECT-1B pin-plan cells (the card's twelve, rows 1 to 6, and four from-first
  cells held at RePark's refusal); and 12 IDENT-DIALECT-1B delta cells (the `f1b_*` relations
  after a VALUES row list, a LATERAL subquery or a `values` column). Read by
  [../test_ident_dialect_1.py](../test_ident_dialect_1.py) (IDENT-DIALECT-1 and 1B).

- [dq_identifiers_config_refuse_1_cells.jsonl](dq_identifiers_config_refuse_1_cells.jsonl) —
  Spark 4.1.2 (Iceberg 1.11.0) answers for `spark.sql.ansi.doubleQuotedIdentifiers`: the
  `SQLConf` entry, 21 `SET`/`RESET` arms, 3 `conf.set` arms and the six DML-reach statements
  with the config off (plus Spark's config-on answers) and under `spark.sql.ansi.enabled=false`
  with the config on. Read by
  [../test_dq_identifiers_config_refuse_1.py](../test_dq_identifiers_config_refuse_1.py).

SHA-256 of the AUD-015 cells file:

`0507e12cfeefc7f6514a32517d2a4a972a91b647838cd3f8427b6b68a8d73377`

- [struct_compare_seat_family_cells.jsonl](struct_compare_seat_family_cells.jsonl) —
  STRUCT-COMPARE-SEAT-FAMILY-1: the 2448 family cells (the delta's 22 `DK` cells included) with
  Spark's outcome (rows by column, class, or the write's read-back), a card for each measured
  out-of-clause cell and each carded class gap (`expect.gap`: a refusal), and the header's
  measured duplicate-name `nullif` rows (`DK22`). Generated by the unit's
  `evidence/pin_cells.py`. Read by the Rust pin and the facade pin.
  **LISTVIEW-INNER-JOIN-KEY-1 (2026-11-11):** the 24 mixed `ListView` × `List` key-name cells
  (`K-KIND`, `df_typed`) lose their `known` marker: they answer Spark's rows, so the pin holds them.
- [listview_inner_join_key_1_cells.jsonl](listview_inner_join_key_1_cells.jsonl) —
  LISTVIEW-INNER-JOIN-KEY-1: a header (each kind's SQL key literal per letter, the step-0 datasets, the
  family views, the pandas route values, each kind's measured Arrow type) and 283 cells, each with its
  oracle: Spark's row count and digest, Spark's twin join for `lateralJoin`, or main's refusal class for
  SQL `USING`. Generated by the unit's `evidence/pin_cells.py`. Read by the facade pin.
- [struct_compare_by_position_cells.jsonl](struct_compare_by_position_cells.jsonl) —
  STRUCT-COMPARE-BY-POSITION-1: the 4393 step-0 cells with Spark's outcome (rows, class, or the
  full persisted read-back; the derived oracle for struct-literal DELETE statements), generated by the
  unit's `evidence/pin_cells.py`. Read by the Rust pin and the facade pin.
- [struct_compare_kind_cells.jsonl](struct_compare_kind_cells.jsonl) — the 435 variant cells
  (seat C P10, ext P30–P35) with their plain-List twin's Spark rows, or a carded refusal; read
  by the facade pin's kind-invariance test.
