## Scope

The replace doors, `CREATE OR REPLACE TABLE … AS SELECT` and `REPLACE TABLE … AS SELECT`, reach
`publish_replace_table` on the local catalog. No pin covered that call before this unit. The build
adds test code only: three cells (K-8, K-9, K-10) on format v2 and v3, and a hold on the replace call in
the test decorator. No product file changes. The records commits touch maps, this ledger, the
registry row, the release-notes draft and the order.

## Rulings

- **RKD-1 (orchestrator, 2026-10-27, order §Step 0 outcome).** The cells pin reading (a): on the
  local catalog the newest metadata file is the commit, as ICE-INTEGRITY-PINS-1 orchestrator ruling
  K-1 states. The staged replace file is written before `publish_replace_table`, so a kill at the
  publish reads back as the replaced table. Reading (b), the seeded pointer, was measured by the
  builder and is not pinned.
- **Discriminator (RKD-1 Q2, test-only).** The `holding` file marks the hold; the `returned` file
  marks that the statement returned. Both live in the cell root, outside the table location.
- **Glue and S3 Tables (RKD-1 Q3).** The catalog pointer governs there. No cell exists (clause C-007).
