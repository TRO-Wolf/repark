## Scope

The seven names are repark plumbing, not PySpark surface: six `Column.*` select-boundary
helpers (`for_select`, `join_sql_part`, `spark_display_part`, `spark_wrap_display_part`,
`sql_expr_part`, `sql_expr_without_alias`) and `F.PythonUDFColumn` (the marker class
`F.udf(f)("n")` returns). The gate gains `INVENTORY_EXCLUSIONS`, a named
`dict[name -> measured reason]` — never a pattern — applied by the new `example_inventory`
view to the snapshot write, the coverage findings and the live `__all__` cross-check. The raw
`enumerate_public_surface` walk still reports all seven, so the API-freeze register
(`docs/design/v1-0-api-freeze.json`, which reads the walk through `build_api_freeze.py`) keeps
them frozen — they remain shipped, callable facade members (D-3). `backlog.txt` drops the
seven rows and `BACKLOG_BASELINE` moves 119 → 112; `inventory.txt` is regenerated by the
script's own `--write-inventory` path (927 → 920 rows). A new pin in
`test_ex_0_example_coverage.py` asserts the seven are in neither the inventory nor the
backlog, and the EX-1 widened-name pin now reads the post-exclusion view. No example file is
added or changed; no §7 registry row moves (the seven never carried one).
