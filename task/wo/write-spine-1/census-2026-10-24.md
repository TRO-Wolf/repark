## Classification

As [`_record_write_spine_1.py`](../../../python/repark/tests/timestamps/_record_write_spine_1.py)
`classify` states it:

- `EQUAL`: the same type and values, or both raise and main's class or text holds Spark's class.
- `DIFFERENT`: both answer differently, Spark raises and main answers, or both raise with another
  class.
- `REFUSED`: Spark answers and main raises a deliberate refusal: a bracketed Spark condition, or
  text that says it refuses, does not support, is not written, or cannot store-assign. A DataFusion
  "This feature is not implemented" error counts here, as in ZONE-ORACLE-1, because its class name
  is `UnsupportedOperationException`.
- `ERROR`: Spark answers and main raises anything else (an Arrow error, a parser error).
- `UNRECORDED`: the Spark fixture holds no answer. There are none.

## Setup choices the order does not fix

These are the recorder's choices, written down so step (2) can re-rule any of them.

1. The U-8 probe's source table `ice.ns.src` is the one-row temp view `write_spine_1_source`; a
   probe spelling that read `(SELECT l FROM ice.ns.src)` reads `(SELECT c_* FROM write_spine_1_source)`.
2. A field-assignment spelling (`merge_update_field*`, `update_field*`) writes `v` on a leaf target
   and `v.a` on a struct target, and does not run on an array, map or struct-in-array target:
   Spark SQL has no assignment to one element.
3. `insert_options` is `writeTo(t).option('snapshot-property.write-spine-1', 'census').append()`.
   `native_insert_conf` sets `spark.sql.iceberg.compression-codec=zstd`: as a session conf on Spark,
   as a build-time conf of a second native session on main.
4. `native_merge` is one MERGE with both arms and no seed row, so the insert arm runs.
   `native_delete` seeds row 1 with the value and row 2 with NULL, then deletes row 2.
5. The native door has no temp views on main (`Temporary views not supported`), so its source
   relation is a table made by the same `SELECT` (`CREATE TABLE write_spine_1_source AS …`). On that
   door `TIMESTAMP '…+00:00'` is a wall clock, so its `c_inst` column is `TIMESTAMP_NTZ`.
6. The native door's target DDL is the native dialect: `TIMESTAMP_LTZ` for an instant column, and
   a `WITH (partitioning = …, extra_properties = MAP(…))` clause for the partitioned and the
   merge-on-read targets. On main `repark.sql()` refuses every `WITH` clause on `CREATE TABLE`
   (`Unsupported SQL statement`) and cannot parse `MAP<…>`; those cells raise at the `create` step
   and are recorded so.
7. The Spark oracle runs the `native_*` spellings as the same SQL text on the Spark session.
