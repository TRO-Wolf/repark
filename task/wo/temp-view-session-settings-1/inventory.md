# TEMP-VIEW-SESSION-SETTINGS-1 — inventory (keys, readers, insertion seats)

Read on main `c22d61a1` (`#1355` only where named); the revision's rows and corrections (marked **revision**) on main
`6f80793b`. "Phase" is where RePark reads the key: **SQL planning** (the
Spark-door router or the SQL planner, under the `SessionContext` that plans the text), **analysis** (an
`AnalyzerRule` given `&ConfigOptions`), **execution** (a UDF reading `args.config_options`, which the physical
planner fixed), or **facade** (Python, at call time). "Spark captures" is read from `CapturesConfig.sqlConfigsToProps`
([sketch.md](sketch.md) §2); "Spark follows" is measured ([domain-table.md](domain-table.md)).
