# T-1 — `repark-spark` tests into one integration binary · grade C · clerk band · tidy window (post-v1.5.2 queue)

## 0. Why, and what is out

`crates/repark-spark/src/tests/` is 166 entries and 87k lines, 61 % of the crate, included from
`src/lib.rs:156` as `mod tests;`. The layout ruling (CL-4, [../roadmap/epic-term/crate-layout-1-8-2026-10-01.md](../roadmap/epic-term/crate-layout-1-8-2026-10-01.md) §5)
moves it to one integration binary `tests/it/main.rs` with one module per former file, so `src/`
holds product code only. **Pure move: no logic changes, no renamed tests, no new tests.** Out:
T-4's directory reshape, any other crate (T-2).

## 1. Rulings already made

- CL-4: clerk tier, no DIFF-PROBE, no verifier; proof = identical `cargo test -p repark-spark` count before and after, plus the gates.
- CL-6: `#[path]` is allowed on a `#[cfg(test)]` child module and nowhere else. T-1 does not need it; do not add one.
- Relocated code sheds its comments (2026-09-18): every comment line in a moved file is deleted in the move, never reworded or carried.
- A test that reaches a private item is **not** made public in this round (halt rule H-2).

## 4. Steps

1. `cargo test -p repark-spark 2>&1 | grep -E '^test result' | tee /dev/stderr | awk '{s+=$4} END {print "BEFORE", s}'` — record the number.
2. `git mv crates/repark-spark/src/tests crates/repark-spark/tests/it && git mv crates/repark-spark/tests/it/fixtures crates/repark-spark/tests/fixtures`, then `ls crates/repark-spark/tests/it/*.rs | xargs -n1 basename | sed 's/\.rs$//' | sort | sed 's/.*/mod &;/' > crates/repark-spark/tests/it/main.rs`. If a `mod.rs` exists among the moved files, its content is what `main.rs` replaces: delete it.
3. Remove the attribute line and `mod tests;` from `src/lib.rs`.
4. `sed -i 's/use crate::/use repark_spark::/' crates/repark-spark/tests/it/*.rs`, then `grep -n 'super::' crates/repark-spark/tests/it/*.rs` and rewrite each hit to `crate::`.
5. Delete every comment line in the moved files: `grep -nE '^\s*//' crates/repark-spark/tests/it/*.rs | wc -l` must print 0 when done.
6. The two `repark-sql` fixture paths, the `EXCEPTIONS` keys, the `--test` filters (step 2 of §2).
7. `cargo test -p repark-spark --no-run 2>&1 | grep -E 'error\[E0603\]|error\[E0433\]|error\[E0432\]'` — any `E0603` line is halt H-2.
8. `cargo test -p repark-spark 2>&1 | grep -E '^test result' | awk '{s+=$4} END {print "AFTER", s}'` — must equal BEFORE.
9. The four map.md edits.
10. `scripts/check_map_md.sh --base origin/main && scripts/check_rust_file_size.sh && scripts/check_lib_rs.sh`. No comment gate exists: the comment ban is held by review and step 5's grep, because the `check-comment-density` ratchet was dropped before #247 merged.
11. Commit: `git -c user.name="TRO-Wolf" -c user.email="64240326+TRO-Wolf@users.noreply.github.com" commit -F msg.txt`, msg.txt = `chore(t-1): repark-spark tests into tests/it — pure move, N tests before and after (CL-4)` plus the `Authored-By:` trailer. Push, open the PR against `main`.

## 6. Halt rules

- **H-1** BEFORE ≠ AFTER: stop, hand back both numbers and the names of the missing tests (`cargo test -p repark-spark -- --list` diffed before and after).
- **H-2** any `E0603` (private item) in step 7: stop, hand back the list of items and the test files that reach them. Do not add `pub`, `pub(crate)` or a re-export. The orchestrator rules each item.
- **H-3** a `--test` filter whose name no longer resolves: hand back the file and line; do not guess a module name.
- **H-4** sixty minutes without a green step 8: commit what exists as `wip(t-1): …`, hand back.
