# PARTITIONBY-NULL-WRITE-1 step-0 table

Live Spark 4.1.2, main's package (built from `57c92b411`, #1429's tested head; main since added Markdown and #1434's
Spark-door SQL text rewrites, which do not touch writes) and the branch head's package. Both ANSI modes are listed.
They agree cell for cell on every engine. The sessions run in UTC, except the `timestamp_ny` and `timestamp_ntz_ny`
cells, which run in `America/New_York`.

## Totals (230 cells: 115 per ANSI mode)

| Verdict against Spark | main | head |
|---|---|---|
| EQUAL: same directories, and live Spark reads RePark's directory as it reads its own | 50 | 124 |
| DIFF | 120 | 46 |
| RePark refuses, Spark writes | 48 | 48 |
| both refuse | 12 | 12 |

- **Fixed.** 74 cells (37 per mode) move from DIFF to EQUAL. 38 more (19 per mode) move toward Spark but stay DIFF.
  In 15 per mode, CSV directories now equal Spark's, but RePark writes a header line in each part and Spark writes
  none. In 4 per mode, a NULL float now lands in `__HIVE_DEFAULT_PARTITION__`, but non-NULL floats keep the demux's
  text.
- **Moved off Spark: 0.** Every cell that equals Spark on main, or refuses on main, answers the same at head.
- **Unchanged.** Data-file rows are the same in all 230 cells, and so are RePark's read-backs of its own and of
  Spark's directories. The only exception is the CSV header line: one more partition directory means one more part,
  and so one more header row.
- **Remaining DIFF at head** (23 per mode): 17 CSV header cells, 5 float cells and the CTAS cell. The card's "Still
  unlike Spark" list has the detail.

`moved` means the verdict changed, or the written directories changed for a write both builds accepted, or the error
class changed for a refusal. Directory lists are the parents of the data files, relative to the write root; `<dir>`
replaces the local work path in error text.

## Scripts

- `probe_partition_null.py` holds the step-0 probe. `--engine spark` or `--engine repark` writes every cell, lists the
  written directories, reads each data file directly, and reads the directory back with the same engine. A RePark
  pass also reads the Spark pass's directory for the same cell. `--engine cross` reads a RePark pass's directories
  with live Spark. `--engine pin-table` turns the Spark pass into the facade pin's
  `partitionby_null_write_1_spark.json`.
- `compare_partition_null.py` builds the verdicts and, given main's table (`--main-table`), this file
  (`--domain-md`).
- **Order:** the Spark pass runs first, because the RePark pass's read-then-write copy reads Spark's directories.
  Then run the RePark pass with `PYTHONPATH` set to the package, the cross pass, and the compare.
