## PARITY-LIVE-STOP-1 — no test stops the shared live-oracle context

**Owner, 2026-10-04 morning:** file card PARITY-LIVE-STOP-1 at clerk grade. "The fix is the
live-cell rule (guard the shared session, never stop it), nothing more. Not a release item."
The owner named `test_ice_meta_delete_1.py`, whose module fixture calls `session.stop()`
(line 131).

### Why

- **What runs:** `parity-live.yml` runs `pytest python/repark/tests` every night with `REPARK_PARITY_LIVE=1`, against one shared PySpark context.
- **The guard:** `_shared_oracle_context_guard` in `python/repark/tests/conftest.py` fails a test when it finds that context stopped or replaced. It also fails when no PySpark session is active.
- **The cascade:** the guard checks after every test, so once the context is gone, every later test fails or errors.
- **NIGHTLY-LIVE-1** (#505, `6fa17a47`) fixed the previous red stretch, 2026-09-05 to 2026-09-11.

### Scope (the live-cell rule, nothing more)

1. **Find every test that stops or clears the shared PySpark session** on a live run. Measure it: run each suspect file alone under `REPARK_PARITY_LIVE=1` followed by one guard-only test. The suspects are the guard's first names on each red night, starting with the three files above.
2. **Apply the live-cell rule to each one:** guard the shared session and never stop it. Nothing else changes.
