# map — task/roadmap/

## Purpose
The roadmap by horizon (DL-1, 2026-08-23). Two bins, deliberately not three: the **short-term**
home is already [../../briefs/next-sequence.md](../../briefs/next-sequence.md) (the ordered slate)
and the state home is [../../STATUS.md](../../STATUS.md); a third directory would be a second home
for the same queue. Promotion is `python3 scripts/ledger_lifecycle.py move <doc> mid-term`
(epic → mid when an intake evaluates it); mid → short is a new brief under `briefs/`, and the
intake is retired by the rule it states at birth.
